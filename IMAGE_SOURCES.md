# Game image sources

Publicly accessible game images added on 2026-10-07. These images are copyrighted game visuals, not openly licensed photographs. They are excluded from the software MIT license. Game visuals remain with FromSoftware / Bandai Namco; community image hosting is identified separately. No permission or endorsement is claimed. Source attribution is not a substitute for a license.

The archive has no advertising or analytics integration. Images identify equipment, encounters and locations; they are not captures of the published builds or gameplay-test evidence. All images are served locally. Original dimensions are preserved when resizing; icons use contain framing. Promotional landscape screenshots are cropped only in cards/hero; detail and enlarged views show the complete image.

`public/media/sources.json` contains every original URL, reference page, retrieval date, generated dimensions and SHA-256 checksums. `src/media-assets.json` is the browser manifest; `src/media-map.json` assigns shared images to builds and guides. Keep all three in sync when replacing imagery. Use material you have permission to redistribute for any commercial release.
